# 🌟 Multi-Page Web Application with Tailwind CSS

> Tailwind CSS와 Vanilla JavaScript를 활용하여 구축한 **반응형 멀티페이지 웹 서비스**입니다. 별도의 백엔드 서버 없이 브라우저의 `localStorage`를 활용하여 데이터 영속성을 구현하고, 대용량 파일 업로드 제약을 극복한 프론트엔드 중심의 실용적인 프로젝트입니다.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, Tailwind CSS (CDN)
* **Script:** Vanilla JavaScript (ES6+)
* **Storage:** Browser `localStorage` (메타데이터 기반 관리 구조)
* **Deployment:** GitHub Pages

---

## ✨ Key Features & Architecture

### 1. 공통 레이아웃 및 반응형 내비게이션
* **사이드바 토글 & 모바일 드로어:** 데스크톱 화면에서는 너비 축소/확장형 토글, 모바일/태블릿 화면에서는 슬라이드 드로어(Drawer) 및 백드롭 오버레이 애니메이션 적용
* **URL 기반 Active 상태 자동 제어:** 공통 스크립트(`script.js`)를 통해 현재 페이지 URL을 파악하고 사이드바 메뉴에 자동으로 활성화(`active`) 스타일 적용

### 2. 자료실 (Archive) - 브라우저 스토리지 한계 극복
* **메타데이터 중심 업로드:** `localStorage`의 5MB 용량 한계 문제를 해결하기 위해, 실제 무거운 파일 바이너리 대신 **파일 메타데이터(제목, 카테고리, 용량, 확장자, 업로드일)**를 구조화하여 저장
* **카테고리 필터 및 실시간 검색:** 매뉴얼, 소스코드, 디자인 에셋 등 카테고리별 분류 및 키워드 즉시 검색 기능 제공

### 3. 대시보드 및 실시간 연동 요약 카드
* **실시간 통계:** 자료실에 등록된 파일 개수와 누적 용량을 실시간으로 계산하여 요약 카드에 반영
* **시스템 현황 및 미니 위젯:** 주간 트래픽 추이 그래프, 시스템 리소스 점유율 바, 자동 저장되는 빠른 메모장 기능 통합

### 4. 개인 메모장 (Memo App)
* **CRUD 완성:** 메모 추가, 수정, 삭제, 리스트 카드 보기, 상세 내용 모달 보기 기능 제공
* **영구 저장:** 작성 즉시 `localStorage`에 자동 동기화되어 새로고침 후에도 데이터 유지

### 5. 환경 설정 및 보안 안전장치
* **프로필 및 알림 설정:** 사용자 닉네임, 이메일, 알림 수신 여부 관리
* **위험 방지 모달:** "모든 로컬 데이터 초기화" 기능 이용 시 실수로 인한 데이터 유실을 방지하기 위해 사용자가 직접 **"초기화"** 문구를 입력해야만 삭제가 실행되는 안전 검증 모달 탑재
